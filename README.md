# CogniType
Within-subject study: copy-typing alone (baseline) vs copy-typing while counting backwards by 7 (dual task).
Order and passage are randomised per participant. Labels: Paas 9-point mental effort scale after each block.
Run: pip install -r requirements.txt; python app.py  (open /admin once to set the researcher password; to reset, delete the admin_hash row or cognitype.db)
Participant link: /?study=NAME&pid=EXTERNAL_ID   Researcher area: /admin
Before real use: replace consent text with your ethics-approved wording and deploy over HTTPS.
